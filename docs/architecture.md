# Архитектура

Домашние рецепты, меню на неделю, общий список покупок и «что есть дома» для двух
человек. Все рецепты халяльные: без свинины и алкоголя.

```
браузер / телефон ──HTTPS──▶ Caddy (hermes) ──▶ recipes (Next.js, 127.0.0.1)
                                                    │  server-side, токен в httpOnly cookie
                                                    ▼
Claude Code (magzhan@hermes) ──stdio──▶ mealie-mcp ──▶ Mealie API (127.0.0.1:9925)
                                                    │
                                                    ▼
                                         SQLite в томе mealie-data
```

## Части

| Часть               | Где                                                                                                                  | Что делает                                                                                                               |
| ------------------- | -------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| Mealie `v3.31.0`    | hermes, `/home/magzhan/apps/mealie`, `127.0.0.1:9925`                                                                | Данные и логика: рецепты, импорт по URL, продукты и единицы, меню, списки покупок, домохозяйство. Наружу не публикуется. |
| Этот репозиторий    | Сборка на Mac, запуск на hermes как у finance-labs: `releases/<sha>` + `current`, systemd, `next start -H 127.0.0.1` | Единственный публичный интерфейс. Ходит в Mealie только с сервера, браузер Mealie не видит.                              |
| mealie-mcp `0.3.24` | hermes, `/home/magzhan/apps/mealie/mcp.sh`, сервер `mealie` в Claude Code пользователя magzhan                       | Доступ Claude к Mealie. Сначала только чтение (`MEALIE_READ_ONLY=true`).                                                 |
| Бэкап               | `mealie-backup.timer` (root), ежедневно 04:30 по времени сервера, `/root/backups/mealie`, 7 дней                     | SQLite копируется через online backup API с `integrity_check`, плюс картинки и секреты тома.                             |

## Вход

Пользователи те же, что в Mealie (двое, одно домохозяйство). Route handler обменивает
логин и пароль на токен Mealie и кладёт его в httpOnly cookie. Каждый handler
проверяет авторизацию сам, middleware не единственная защита.

Админка Mealie только через туннель:

```bash
ssh -L 9925:127.0.0.1:9925 hermes
```

## Как circle ложится на рецепты

| circle         | здесь                         |
| -------------- | ----------------------------- |
| issues         | рецепты                       |
| cycles         | меню на неделю                |
| inbox          | список покупок                |
| labels         | теги и категории              |
| members, teams | домохозяйство                 |
| projects       | кулинарные книги (cookbooks)  |
| ⌘K             | поиск и импорт рецепта по URL |

Первая версия читает рецепты, импортирует по URL, планирует неделю, ведёт список
покупок и «есть дома». Редактирование рецептов пока в интерфейсе Mealie.

## «Есть дома»

В Mealie это только флаг «есть / нет» на продукте для домохозяйства, без количества.
Если нужно количество (как в `food/INVENTORY.md`), его храним во втором списке покупок
«Дома»: у позиции списка есть продукт, количество и единица.

## Типы API

Генерируются из `openapi.json` Mealie `v3.31.0`, снимок хранится в репозитории.
При обновлении Mealie сначала обновить снимок и типы.
